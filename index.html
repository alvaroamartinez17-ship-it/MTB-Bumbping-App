    Send a day of rides

      Bundles every ride from one day into a single CSV, one row per second, each row tagged with which ride it came from. A full day is usually well under 100 KB, small enough to copy and paste.

      Copy all of it puts the whole file on the clipboard. Paste it into Notes, save the note, and you have it on the phone for later. For the summary export this is the route that always works.

      Save to Files opens the iOS share sheet, then pick Save to Files and On My iPhone. iOS only shares file types it recognises, so this tries plainer and plainer versions of the same data until one is accepted.

      Share it as a message sends the contents as text rather than a file, which works for the summary but not for a long raw export.

      Download it works in Safari but does nothing when the app is launched from the home screen, because a home screen app has no download manager.
